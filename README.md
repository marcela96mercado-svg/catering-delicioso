# 🍴 Catering Delicioso

Bienvenido a **Catering Delicioso**, una agencia especializada en **catering y organización de eventos**.  
Ofrecemos experiencias gastronómicas únicas para todo tipo de celebraciones: bodas, eventos empresariales, fiestas privadas y más.  

## 🚀 ¿Qué encontrarás aquí?
Este repositorio contiene el código de nuestra **página web oficial**, publicada con GitHub Pages.  
En ella encontrarás:
- Información de nuestros **servicios**  
- Nuestro **menú destacado**  
- Datos de **contacto** para reservar tu evento  

👉 Visita la página aquí: [Catering Delicioso en GitHub Pages](https://TU-USUARIO.github.io/catering-delicioso/)

## 🎉 Servicios
- Banquetes para **bodas**
- **Eventos corporativos**: coffee breaks, almuerzos ejecutivos, cenas empresariales
- **Fiestas privadas**: cumpleaños, reuniones familiares, aniversarios
